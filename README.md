🚀 Smart Factory Data Analysis Dashboard:
By an Electronics and Instrumentation Engineering Student

Overview
This repository showcases my first machine-based data analysis dashboard built with Power BI, where I bridge engineering concepts and data analytics to deliver actionable insights for industrial systems. The dashboard enables users to monitor and analyze key machine metrics, supporting smarter and more efficient manufacturing processes.

Dashboard Features:
•Machine-wise Failure Distribution:
Visualizes which machines experience the highest failure rates, helping pinpoint operational bottlenecks.

•Torque vs Process Temperature (Anomaly Detection):
Correlates torque and process temperature to highlight abnormal machine behavior and potential faults.

•Machine Type Composition:
Shows the proportions of high, medium, and low-performance machines in your factory.

•Failure Risk Index:
Compares the risk and severity of failures across machine categories for data-driven risk management.

Key Insights:
•Transform raw machine and maintenance data into clear business intelligence
•Enable targeted maintenance with anomaly and failure analysis
•Provide real-time machine health monitoring
•Empower decision-making in smart manufacturing environments
